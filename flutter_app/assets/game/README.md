# 게임 에셋 슬롯

여기에 PNG 를 넣으면 코드 드로잉 대신 그림이 쓰인다. **없어도 게임은 돌아간다** —
각 컴포넌트가 같은 구도로 코드 드로잉 폴백을 갖고 있다.

| 파일 | 쓰는 곳 | 권장 |
|---|---|---|
| `stadium.png` | `Stadium` 배경 | 1인칭 타석 뷰 카툰 야구장. 화면 비율에 맞춰 늘어나므로 여유 있게 |
| `glove_open.png` | `Glove` (펴짐) | 정면 글러브, 배경 투명 |
| `glove_closed.png` | `Glove` (쥠) | 같은 구도에서 손가락이 말린 상태 |
| `pitcher.png` | `Pitcher` 투구 모션 | 가로로 이어붙인 프레임 시트(현재 미사용, 로더 추가 필요) |

파일을 넣은 뒤 `pubspec.yaml` 의 `assets:` 에 `- assets/game/` 이 있는지만 확인하면 된다.
